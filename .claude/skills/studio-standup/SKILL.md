# studio-standup — 現況報告

スタジオヘッドとして実行する。部署エージェントは使わず、自分でファイルと履歴を読んでまとめる。

## 確認するもの

- `studio/projects/` の各プロジェクトと `gates/` の最新記録（現在のフェーズ）
- `studio/decision_log.md` の直近の決裁
- `git log` の直近のスタジオ関連コミット
- `studio/tooling.md` の未解決事項

## 報告の形（短く）

1. **プロジェクトごと**: 現フェーズ / 次のゲートとその基準 / 前回からの進捗 / 次のアクション
2. **ディレクターの判断待ち**: 何を、いつまでに決める必要があるか
3. **止まっていること**: 理由と解除に必要なもの

プロジェクトがまだない場合は、その旨と、次の一手（`/studio-kickoff`）を伝える。
ファイルや履歴から確認できたことだけを書く。確認できない進捗は書かない。
