# Fable AI Game Studio — ワークスペース

このワークスペースはゲーム制作スタジオの本部。ディレクターは Taichi、Claude はスタジオ統括（モデルは Fable）。

- 運用ルール: `studio/CLAUDE.md`（最初に読む）
- 組織とモデルの使い分け: `studio/README.md`
- 制作フェーズとゲート: `studio/pipeline.md`
- 決裁の記録: `studio/decision_log.md`
- ツールの導入状況: `studio/tooling.md`
- Unity制作キット: `studio/unity-kit/`（Unityプロジェクトのルートは、このワークスペースとは別のフォルダに作る）

## このワークスペースの範囲

- ここに置くのは、スタジオの文書・部署エージェント・運営スキル。
- ゲームのUnityプロジェクト、他エンジンやC++のラボは、それぞれ別フォルダ。
- 既存の作品（UEFN、Web）と Verse Memory のリポジトリ、Claude Code のグローバル設定は変更しない。

## ディレクターの承認が要ること

有償のもの、アカウント接続やAPIキー、クラウドへの送信、外部公開（GitHubへのリポジトリ作成とpushを含む）、このワークスペースの外のファイルの変更。
