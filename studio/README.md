# Fable AI Game Studio

ゼロベースでオリジナルゲームを企画・制作し、収益化するためのAIゲームスタジオ。
ディレクター（人間）1名と、Claudeが統括する部署エージェント群で構成する。

## 組織図

```
ディレクター（Taichi）── 最終意思決定
        │
スタジオヘッド（Claude メインセッション）── 統括・発注・統合・上申
        │
        ├─ プロデュース部 ─────────── producer
        ├─ 事業戦略部 ─────────────── market-analyst / monetization-designer
        ├─ 企画・ゲームデザイン部 ─── game-designer
        ├─ エンジニアリング部 ─────── gameplay-engineer
        ├─ アート部 ───────────────── art-director
        ├─ ナラティブ部 ───────────── narrative-designer
        ├─ サウンド部 ─────────────── sound-designer
        ├─ QA部 ───────────────────── qa-lead
        └─ マーケティング部 ───────── marketing-lead
```

## 部署一覧

| 部署 | エージェント | 責任範囲 | 主な成果物 |
|---|---|---|---|
| プロデュース部 | `producer` | スコープ・スケジュール・リスク管理 | マイルストーン計画、リスク台帳、進捗レポート |
| 事業戦略部 | `market-analyst` | 市場・競合・プラットフォーム調査 | 市場調査レポート、機会リスト |
| 事業戦略部 | `monetization-designer` | 収益モデル・価格・KPI設計 | 収益化設計書、KPI目標、収支試算 |
| 企画・ゲームデザイン部 | `game-designer` | コアループ・ルール・バランス | コンセプトピッチ、GDD、バランス表 |
| エンジニアリング部 | `gameplay-engineer` | 技術選定・実装・ビルド | 技術設計、プロトタイプ、本実装 |
| アート部 | `art-director` | ビジュアル方針・アセット仕様 | アートバイブル、アセットリスト、UIモック |
| ナラティブ部 | `narrative-designer` | 世界観・テキスト | 世界観設定、シナリオ、ゲーム内テキスト |
| サウンド部 | `sound-designer` | BGM/SE方針・音仕様 | サウンド設計書、音素材リスト |
| QA部 | `qa-lead` | テスト計画・品質判定 | テスト計画、バグ報告、リリース可否判定 |
| マーケティング部 | `marketing-lead` | 訴求・ストアページ・コミュニティ | ポジショニング、ストア文面、発信計画 |

エージェント定義は `.claude/agents/` にある。

## 決裁権限

| 事項 | 決める人 |
|---|---|
| どのゲームを作るか（ゲート通過／中止） | ディレクター |
| 予算・課金を伴う外部サービスの利用 | ディレクター |
| 外部公開（ストア公開、SNS投稿、広告出稿） | ディレクター |
| 部署への発注、作業順序、成果物の統合 | スタジオヘッド |
| 部署間の意見対立の整理と推奨案の提示 | スタジオヘッド（最終判断はディレクター） |
| 各部署の専門領域内の設計判断 | 各部署（ゲートで審査される） |

## 使い方

| コマンド | 用途 |
|---|---|
| `/studio-kickoff` | Phase 0（探索）を実行。市場調査 → コンセプトピッチ3案を上申 |
| `/greenlight <project>` | 現フェーズのゲート審査。全部署の評価をまとめ、Go / 条件付きGo / Kill を推奨 |
| `/studio-standup` | 進行中プロジェクトの現況・次アクション・ディレクター判断待ち事項を報告 |

コマンドを使わず普通に話しかけても良い（「この案のマネタイズを詰めて」など）。スタジオヘッドが適切な部署に発注する。

## 制作現場（Unity）

1本目は新規Unityプロジェクト（Windows、URP）で作る。制作現場用の6担当・計画・ツール台帳は [`unity-kit/`](unity-kit/) にまとめてあり、Windows上の新規Unityプロジェクトのルートにコピーして使う。

| 層 | 場所 | 役割 |
|---|---|---|
| スタジオ本体 | このリポジトリの `studio/` と `.claude/` | 何を作るか・続けるかを決める（企画、事業、ゲート審査） |
| 制作現場 | 新規Unityプロジェクトのルート（`unity-kit/` の中身） | どう作るか（director / builder / artist / world-builder / tester / release） |
